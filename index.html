Quiz Page Generator

Paste a spreadsheet of questions below and generate a single, self-contained quiz page. Copy the path and code straight into GitHub, or download the file.

Groups related quizzes into one folder. Use "Trial Quizzes" while testing.

Leave blank to use the Quiz Name from a full-format sheet.

A folder-per-subject scheme keeps this manageable as the number of quizzes grows:

  1. One folder per class or subject: spanish-quizzes/, cs-foundations-quizzes/.
  2. A separate trial-quizzes/ folder for anything you're still testing — safe to delete without touching real quizzes.
  3. Inside a folder, name quizzes by unit or topic so they sort in order: unit-3-vocabulary.html, unit-4-vocabulary.html.
  4. The "Recently generated" list above tracks the path and link for everything you've made here, so you don't have to hunt through GitHub to re-copy a link.
  1. Create (or open) a GitHub repo and turn on Pages for it (Settings → Pages → Deploy from branch).
  2. Upload styles.css to the repo root once — every quiz page you generate here shares it.
  3. In the repo, click Add file → Create new file, paste the copied path (e.g. trial-quizzes/unit-3-vocabulary.html) into the name box, then paste the copied code into the editor and commit.
  4. Share the copied link with students.
