Quiz Page Generator

Paste a spreadsheet of questions below and generate a single, self-contained quiz page. Download it, drop it in this repo next to styles.css, and share the link.

Suggested filename:

  1. Create (or open) a GitHub repo and turn on Pages for it (Settings → Pages → Deploy from branch).
  2. Upload styles.css to the repo root once — every quiz page you generate here shares it.
  3. Download a quiz page above and upload the file to the same repo.
  4. Open https://yourusername.github.io/yourrepo/filename.html and share that link with students.

Column A: Scramble choices? (TRUE/FALSE) · Column B: Question · Column C: Answer · Columns D+: Choices (leave blank for a typed-answer question). For the full format, add Subject, Quiz Name, and Notes as label/value pairs after the choice columns in row 1 only.
