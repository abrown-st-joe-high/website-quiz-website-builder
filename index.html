Opens in a new tab, formatted for paper. Use the page's own Print button (or Ctrl/Cmd+P) and choose "Save as PDF" as the destination.

Create a Google Form with five short-answer questions, in any order: Class Code, Student Name, Quiz Name, Score, Total. Open the form, choose Get pre-filled link from the menu, then on the pre-filled version type exactly CLASSCODE, STUDENTNAME, QUIZNAME, SCORE, TOTAL (one word, capitals) into the matching questions, click Get Link, copy it, and paste it above. In the Form's Responses tab, create the linked Sheet. In that Sheet: File → Share → Publish to web → CSV — paste that link into dashboard.html to watch results live.

  1. One folder per class or subject: spanish-quizzes/, cs-foundations-quizzes/.
  2. A separate trial-quizzes/ folder for anything still being tested.
  3. Name quizzes by unit or topic so they sort in order: unit-3-vocabulary.html, unit-4-vocabulary.html.
  4. Regenerating the same folder + name bumps the version shown on the page and in the list above, so it's clear which copy is newest.
  5. Use Load to edit in the list above to pull a past quiz back into the form to tweak and regenerate.
  1. Create (or open) a GitHub repo and turn on Pages for it (Settings → Pages → Deploy from branch).
  2. Upload index.html, styles.css, and dashboard.html to the repo root once.
  3. For a brand-new path: Add file → Create new file, paste the copied path into the name box, paste the code, commit.
  4. For a path already in the repo (version 2 or later): open that file on GitHub, click the pencil (Edit), replace the contents with the copied code, commit.
  5. Share the copied link. To watch results live, open dashboard.html on the site and paste the published Sheet CSV link and a class code.
